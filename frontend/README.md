# Frontend · Tarnished's Codex

- `templates/` — `base.html`, `mapa.html` (pantalla principal), `registro.html` (detalle), `acerca.html`, y la plantilla del admin que permite colocar pines con un clic.
- `css/codex.css` — estilos según `DESIGN.md`.
- `js/mapa.js` — mapa con Leaflet (CRS.Simple sobre imágenes), capas, pines, panel de categorías, búsqueda y fases de misión.
- `img/mapas/` — originales de los mapas; `img/mapas/web/` — versiones ligeras que usa el sitio.

Leaflet 1.9.4 se carga desde unpkg; las tipografías (Cinzel, Cormorant Garamond) desde Google Fonts.
